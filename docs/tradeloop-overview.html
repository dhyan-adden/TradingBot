TradeLoop — How the Pipeline Works

An agent-driven, India-only, news-discovery-first paper trading loop for cash equities. Python does all deterministic work (fetch, tickers, indicators, sizing, cost model, risk gate, ledger). An LLM reasoning DAG does the judgment — through file boundaries. Every order passes two deterministic gates before it can fill. Cycles are propose-only: they stop at AWAITING_APPROVAL until a human routes them.
