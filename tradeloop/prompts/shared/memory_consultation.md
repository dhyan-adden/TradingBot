# Memory Consultation

Before recommending a ticker or strategy family, read the relevant durable
memory:

- `memory/lessons_learned.md`
- `memory/strategy_performance.md`
- `memory/trade_journal.md`
- `memory/stock_dossiers/<TICKER>.md` if it exists
- `memory/debate_archive/` for recent debates on the same ticker

Cite memory when it materially changes a decision. Do not duplicate lessons;
increment confidence or note repeat evidence instead.
